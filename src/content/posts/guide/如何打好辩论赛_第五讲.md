> **本篇说明**：本讲是"辩题基本功"专题——把辩题分为**事实、价值、政策、哲理**四类，每类附赛事案例和专用备赛教程，最后给出通用备赛流程与四种常见死法。原文内容未作改动，仅做排版整理。

## 引言

辩题，是所有辩论赛比赛绕不开的东西。

比赛围绕辩题而展开，我们讨论的东西也是辩题，很多辩论新手也会从辩题里去观察哪一方更好打、哪一方"我"更支持。

但是，辩题也是有类别的，了解辩题的分类和不同辩题的侧重点，对我们辩论备赛也具有重要作用。

事不宜迟，我们开始这一课！

（华语辩论界主流采用**"事实—价值—政策"三分法，这也是逻辑学和论辩学中对争议命题的经典划分）

---

## 一、事实辩（描述性辩题）

核心问题："是不是"

- 胜负点：1. 概念操作能不能被数据量化；2. 举证责任在哪一方身上
- 典型结构：X 是 / 不是 Y；A 导致 / 未导致 B。
- 主要看什么？：定义界定、数据。
- 新国辩案例：《网络舆论能/不能提升民主觉醒》（2013 首届新国辩），《AI 绘画是不是艺术？》（新国辩哲理辩特别场），《武侠是/不是一场梦》（经典哲理辩题）

说明：新国辩正赛中纯事实类辩题占比不高，更多事实判断被包裹在价值或政策辩题中。

### 经典案例一览

| 辩题 | 出处 | 类型要点 |
| --- | --- | --- |
| 金钱是／不是万恶之源 | 2001国际大专辩论赛决赛（武大 vs 马来亚大学） | 典型事实＋定义争夺题，"万恶之源"的外延界定决定全场 |
| 网络使人更亲近／更疏远 | 早期华语经典题 | 因果归因＋指标选取（"亲近"如何测量） |
| 寒门难出／不难出贵子 | 2015世界华语辩论锦标赛半决赛 | 社会流动性的经验命题，完全靠数据与口径 |
| 《原神》的出现是／不是国产游戏的黎明时刻 | 2021华语辩论世界杯 | "黎明时刻"的事实判定＋行业指标 |
| 网络暴力的根源是恶意／愚蠢 | 2025新国辩 | 归因型事实辩，争的是因果主因 |
| "内娱没有活人"是对大众精神需求的满足／背离 | 2025新国辩初赛 | 现象归因＋效果事实 |
| 预制菜成为堂食主流，总体提升／降低消费者福利 | 2026新国辩初赛B组 | 福利效应的经验评估，最接近政策评估的事实化表达 |

### 备赛教程（事实辩专用）

第一步：把辩题翻译成可检验的命题。 写出"若X成立，则在Y指标上应观察到Z"。例如"学历贬值下要继续向上卷"的事实层面可拆为：向上卷的投入产出比是否仍为正？这需要具体的回报率、岗位门槛数据支撑。

第二步：抢定义与指标权。 事实辩80%的胜负在"怎么算"。谁定义了测量口径（如"孤独感"用量表还是用社交频次、"贵子"用收入还是用阶层跃迁），谁就掌握了主动权。定义必须中性、可操作、有权威来源背书（词典、学术量表、官方统计口径），切忌极端偷换——一旦被评委识破，整队信用崩塌。

第三步：建立证据金字塔。 优先级：官方统计／系统性综述 ＞ 同行评议论文 ＞ 权威媒体报道。个人经历只能作修辞，不能作论据。

第四步：做反方资料包。 主动搜集对己方不利的研究与数据，提前准备解释框架（样本偏差、口径不同、时间窗口、第三变量）。场上被对方拿出不利数据时，能从容说明"这份研究恰恰说明……"是极强的加分项。

## 二、价值辩（规范性辩题）

核心问题："好不好 / 对不对 / 哪个更重要"

- 胜负点：数据基本失效，真正决定胜负的是该用哪把尺子（判定标准）衡量。
- 典型结构：X 比 Y 更重要；X 是/不是一种好的生活方式；X 更可贵/更可怕。
- 辩论关键：不能只靠数据，要靠价值反证出哪一方的判标更正确、更可行、更普遍适用。
- 新国辩案例：
- "拥有执念是人生之喜还是人生之悲"（2016）
- "爱情中铭记/遗忘更可贵"（2017 第五届）
- "被同化/排斥更可怕"（2017 第五届）
- "权利天赋还是人赋"（2016）
- "责任大小应/不应和能力挂钩"（2016）
- "发现自己终究只是一个平凡的人，要/不要遗憾"（2026 新国辩决赛辩题）

### 经典案例一览

| 辩题 | 出处 | 类型要点 |
| --- | --- | --- |
| 人性本善／本恶 | 1993国际大专辩论赛决赛（台大 vs 复旦） | 本末型价值辩，结辩"认清黑暗才更懂追寻光明"是价值升级范本 |
| 顺境／逆境更有利于人的成长 | 2003国际大专辩论赛决赛 | 比较型价值辩，争"成长"的定义与衡量 |
| 大学生谈恋爱利大于弊 | 校园经典题 | 利弊权衡的标准之争 |
| 被误解是／不是表达者的宿命 | 2019华语辩坛老友赛 | 切割法范本："会发生"≠"宿命"，偶然≠必然 |
| 向下的自由是／不是自由 | 2025新国辩半决赛 | 概念＋价值复合，反方直接否定对方的价值评判体系 |
| "幸福者退让论"是善的智慧／对恶的纵容 | 2025新国辩复赛 | 道德评价的标准之争 |
| 我"厌蠢"，我错了／我没错 | 2026新国辩复赛GH组 | 自我道德评价＋公共伦理 |
| 发现自己终究只是一个平凡的人，要／不要遗憾 | 2026新国辩决赛 | 人生价值取向，典型的"没有标准答案但要说服你" |
| "勇敢的人先享受世界"是／不是一个陷阱 | 2026华语辩论世界杯总决赛 | 流行话语的价值审视 |
| 身处奥德赛时期的青年人，应该／不应该追求确定性 | 2026华语辩论世界杯 | 青年处境的价值选择 |

### 备赛教程（价值辩专用）

第一步：拆解四要素——主体（谁的价值）、范围（什么情境下）、核心概念（逐一定义）、判准（比较标准）。判准是价值辩的灵魂，必须是一个能让评委用来裁决的具体标准，而不是口号。常见判准类型：

- 损益比型（整体福祉增减）
- 权利／尊严优先型（某些价值不可交易）
- 弱势群体保护型（罗尔斯差异原则思路）
- 长期／短期、个体／群体二维矩阵
- 可行性与现实代价型

第二步：确立价值主线，最多三条论点。 建议顺序：主论点在前、现实层面先于精神层面。每条论点配"逻辑链＋学理＋案例"，且三点之间不重复不交叉。

第三步：预设对方的价值高地并提前占领。 价值辩最大的风险是被对方垄断"善良""自由""人性"等词。做法是重新解释而非放弃：承认对方价值的正当性，但说明在本题情境下它从属于更高或更紧迫的价值。

第四步：准备"人"的材料。 价值辩需要具象案例与可共情的处境描写，但案例必须真实、有出处，且能代表一类人而非孤例。

## 三、政策性辩题（行动性辩题）

核心问题："应不应该 / 要不要 / 是否采取某行动"

- 胜负点：围绕某项政策、制度或社会措施的存废展开，属于"行不行"之争。需要完整论证可行性
- 典型结构：应当/不应当 X；X 应该合法化/禁止；国家/社会/个人有义务/无义务做 Y。
- 辩论关键：正方需提出具体方案并证明其可行；反方可以攻击需求不成立、问题根深蒂固无法解决、或方案弊大于利。
- 新国辩案例：
- "中国应不应该征收遗产税"（2017 第五届）
- "国家有无义务减少离婚"（2017 第五届）
- "应不应该限制艺人的天价酬劳"（2016）
- "性交易合法化是/不是国家进步的表现"（2013 首届）
- "精英移民应该/不应该被谴责"（2013 首届）
- "法海该不该拆散许仙和白素贞"（2016）——以文艺故事形式包裹的政策/伦理辩题

特点：卷数据、少见

### 经典案例一览

| 辩题 | 出处 | 类型要点 |
| --- | --- | --- |
| 安乐死应否合法化 | 多国赛事经典 | 合法化的制度设计与风险控制 |
| 我国应不应该取消死刑 | 经典政策题 | 需求性（误判不可逆）vs 根属性（威慑力争议） |
| 董事会性别配额制有／无助于实现职场性别平权 | 经典政策题 | 手段有效性＋副作用（逆火效应） |
| 中国应强制推行垃圾分类 / 应建立个人破产制度 | 训练常用题 | 态度性根属性／缺口性根属性的标准范例 |
| 美国大学应该取消早申轮次 | WSDA冬季赛冠军赛题 | 制度微调型政策辩，争根属性与替代方案 |
| 当今中国，建立无障碍社会更需要完善制度／唤起观念 | 2026新国辩初赛G组 | 政策工具比较型（更接近价值＋政策混合） |
| 在当下，优先推动减工时／加工资更有助于实现打工人福祉 | 2026新国辩初赛E组 | 双方案比较型政策辩，争"何者更有效" |
| 基因编辑应不应该大力推行 | 训练常用题 | 技术政策的损益比与监管配套 |

## 四、哲理辩（和价值辩很像）

核心问题："某个（哲理）概念到底该怎么理解"

- 胜负点：拆解概念、指出题目不是完全二元二分、构建自圆其说的"漂亮话"。
- 典型结构：X 比 Y 更重要；X 是/不是一种好的生活方式；X 更可贵/更可怕。
- 辩论关键：数据几乎失效，举例要生动，观感要好，价值高度要高。
- 新国辩案例：
- "如果注定无法成功 要/不要 继续努力"（2024新国辩决赛）
- "人 是/不是 生来自由"

特点：一般放决赛，观感好，综合性强。要求辩手思维深度更高、表达能力更强、能打动评委和观众。

### 经典案例一览

| 辩题 | 出处 | 看点 |
| --- | --- | --- |
| 真理会越辩越明／不会越辩越明 | 1997国际大专辩论赛决赛 | 自我指涉型：辩论本身即是对题目的检验 |
| 美是主观感受／客观存在 | 1999国际大专辩论赛 | 美学本体论，定义战 |
| 温饱是／不是谈道德的必要条件 | 1993国际大专辩论赛 | 必要条件型的哲理＋价值混合题 |
| 知难行易／知易行难 | 1995国际大专辩论赛决赛 | 知行关系的古典命题 |
| 人有没有表达偏见的自由 | 2018新国辩哲理辩论（周玄毅 vs 黄执中） | 自由与伤害的经典张力 |
| 自由意志存在／不存在 | 新国辩哲理辩 | 归谬法范本：若无自由意志，道德奖惩与法律制裁失去根基 |
| 博物馆着火，救猫还是救画 | 2017新国辩 | 价值冲突的极端情境化 |
| 世界是荒谬的／不是荒谬的 | 2018华语辩坛老友赛 | 存在主义命题 |
| 决定相伴一生的爱侣，要／不要打上永远爱对方的"思想钢印" | 2023新国辩哲理辩论Ⅱ | 爱的本质与自主性 |
| 当今时代，我们更需要意义的解构／建构 | 2025新国辩哲理辩论（黄执中 vs 熊浩） | 元层次打法范本：正方论证"这个辩题的存在本身就已经是解构精神的体现" |
| 彻底失去记忆后的全新人生，该／不该对之前犯下的罪行负责 | 2026新国辩哲理辩论 | 人格同一性＋道德责任，典型分析哲学式命题 |
| 语言的边界是／不是人类的边界 | 2026新国辩半决赛 | 语言哲学，维特根斯坦脉络 |
| 爱欲已死／爱欲未死 | 2026新国辩半决赛 | 精神分析／社会批判脉络 |

## 五、通用备赛流程

| 阶段 | 时间占比 | 做什么 |
| --- | --- | --- |
| 分析辩题 | 15% | 语法拆分（主谓宾）、关键词的定义、确认辩题类型、确定判准、归纳正反两方核心论点与逻辑链 |
| 查资料 | 20% | 查资料、查数据、查定理、看类似辩题； |
| 立论定稿 | 20% | 全队共同确立论点、判标、定义（必须所有人明确，不要各打各的） |
| 模拟攻防 | 30% | 写稿→模拟→改稿→再模拟。准备自由辩短打和套题（检验时间 ≥ 生产时间） |
| 补漏＋打磨表达 | 15% | 补双方在自由辩产生的新论点。改稿优化表达（四辩、一辩，以及其他陈词环节） |

## 六、四种辩题常见死法（没有站在胜负点上就是game over）

| 类型 | 典型翻车 |
| --- | --- |
| 事实辩 | 定义模糊、数据口径被击穿、把相关当因果、用个案当普遍 |
| 价值辩 | 纯抒情无判准、被对方垄断核心词、脱离代言的群体 |
| 政策辩 | 只讲应然不讲可行、根属性与解决力混淆、不给方案细节 |
| 哲理辩 | 飘在空中不落概念、定义过宽导致不可证伪、用修辞代替推理 |

## 补充

老师的话：现阶段大部分辩题都是混合型，没有绝对的标杆，部分辩题则是严格按照分类。辩题类型只是参考，助于你了解胜负依据。
